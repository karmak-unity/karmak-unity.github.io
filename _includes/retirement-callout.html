Important: Unity Retirement and Migration to Unity Pro

Karmak is retiring the Unity platform. Unity access will end on March 31, 2027.

If you currently have integrations using Unity APIs, you must migrate those integrations to Unity Pro before March 31, 2027. After this date, Unity APIs will no longer be available and integrations that have not been migrated will no longer function.

We encourage you to begin planning your migration now to allow adequate time for development, testing, and deployment.

Migration deadline: March 31, 2027
